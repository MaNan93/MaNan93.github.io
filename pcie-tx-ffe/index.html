一页速记

FFE
Feed-Forward Equalizer，本质是 FIR；使用原始 symbol x[] 的相邻样本加权产生 Tx 输出 y[]。
x[] / y[]
x[] 是未经 FFE 的原始 symbol；y[] 是 FFE 后输出。不要把 y[n-1] 递归代回。
C-2 / C-1 / C0 / C+1
2nd pre-cursor / 1st pre-cursor / main cursor / post-cursor。
Pre-Shoot / De-emphasis
是 Tx 波形/电压 ratio 的表现；与 pre/post cursor 强相关，但不等同于 coefficient 本身。
P4 / Q0
分别是 Gen3~5 P-family 与 Gen6 Q-family 的 No-EQ / flat reference。

1. FFE 的核心模型

本次学习中最关键的认识是：公式中的 x[] 是未经 FFE 调制的原始 symbol。FFE 是 feed-forward/FIR，不是把已经发送过的 y[] 再反馈回来。

y[n] = C-2·x[n+2] + C-1·x[n+1] + C0·x[n] + C+1·x[n-1]

这里采用与 PCIe cursor 位置一致的时间索引：C-2/C-1 位于 main 之前，C+1 位于 main 之后。连续相同 symbol 不会无限向 0 衰减；有限 tap 的影响结束后会进入稳定电平。

2. Cursor 与波形效果

Cursor 位置

time →
 C-2       C-1       C0       C+1
  │         │         │         │
2nd Pre   1st Pre    Main      Post

最重要的区分

Pre-cursor / post-cursor 是 FFE tap 位置。

Pre-Shoot / De-emphasis 是最终波形与 PCIe 定义的 equalization ratio。

PCIe Figure 8-6 对应的电压定义

Va  = (+C-2 + C-1 + C0 - C+1)
Vb  = (+C-2 + C-1 + C0 + C+1)
Vc1 = (+C-2 - C-1 + C0 + C+1)
Vc2 = (-C-2 + C-1 + C0 + C+1)
Vd  = (-C-2 - C-1 + C0 - C+1)

De-emphasis = 20 log10(Vb / Va)
Pre-Shoot 1 = 20 log10(Vc1 / Vb)
Pre-Shoot 2 = 20 log10(Vc2 / Vb)
Boost       = 20 log10(Vd / Vb)

3. Gen3~Gen5：P Preset

固定 P preset 主要使用 C-1、C0、C+1，C-2=0，因此可以从 3-tap FFE 的角度理解。

快速分类： P0~P3 = pure de-emphasis；P4 = No EQ；P5/P6/P9 = pure pre-shoot；P7/P8 = pre-shoot + de-emphasis。

4. P4 失败意味着什么

P4 没有 Tx FFE。如果 Gen3 在 P4 下失败，最直接只能说明：8 GT/s 下 No-EQ 的 channel margin 不足。

P4 fail
  ├─ P0~P3 pass     → post-cursor compensation 有效
  ├─ P5/P6/P9 pass  → pre-cursor compensation 有效
  ├─ P7/P8 pass     → pre + post 组合有效
  └─ all fail       → 继续检查 RX EQ / channel / jitter / termination / SI ...

典型 PCIe channel 中 post-cursor ISI 常很重要，因此工程上经常优先尝试带 post-cursor 的 preset；但这不是协议规定。

5. 3-tap → 4-tap

3-tap:          C-1    C0    C+1
4-tap:     C-2  C-1    C0    C+1

对数字设计者来说，最简单的理解就是：多了一个 2nd pre-cursor 自由度。本质还是 FIR。4-tap 与 PAM4 是两个不同维度，不能简单写成 “PAM4 ⇒ 4-tap”。

6. Gen6：Q Preset Family

Q* 是一套重新定义的 preset family，不能把 Qn 当成 Pn 的自然延续。功能上，P4 与 Q0 都是 No-EQ reference。
